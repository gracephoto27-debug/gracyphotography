# Cinematic video uploads

Upload these six MP4 video files with exact names:
- `film-01.mp4`
- `film-02.mp4`
- `film-03.mp4`
- `film-04.mp4`
- `film-05.mp4`
- `film-06.mp4`

Films 01–02 appear on the homepage; films 03–06 appear on `cinematic-videos.html`. Click the designed video frames to load the MP4 file. Optional posters go into the `posters/` subfolder as `film-01.jpg` through `film-06.jpg`. See [full upload guide](../../ASSET-UPLOAD-GUIDE.md).
